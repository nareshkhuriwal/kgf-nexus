# Code of conduct

KGF Nexus adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in every project space (issues, pull
requests, discussions and reviews) and when someone represents the project
elsewhere.

In short: be respectful and constructive, assume good intent, welcome people
of every background and level of experience, and focus criticism on the work,
not the person. Harassment, insults, personal attacks and publishing others'
private information are not acceptable.

## Reporting

Report unacceptable behaviour to the maintainers privately: through the
repository's **Security** tab (**Report a vulnerability** creates a private
report only the maintainers can read), or by contacting a maintainer
directly on GitHub. Reports are handled confidentially.

## Enforcement

The maintainers enforce this code using the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
a correction, a warning, a temporary ban or a permanent ban, depending on the
impact of the behaviour.
