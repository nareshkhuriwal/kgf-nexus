# The Nexus SDK is deliberately NOT listed. Its distribution name, nexus-sdk,
# belongs on PyPI to an unrelated project (Blue Brain Nexus), so
# `pip install nexus-sdk` from a public index installs the wrong package and
# every task then fails with "No module named nexus". Install the SDK from a
# Nexus checkout instead:
#   locally:        pip install -e /path/to/kgf-nexus/sdk/python
#   in the image:   docker build --build-context nexus-sdk=/path/to/kgf-nexus/sdk/python ...
# or from your own index, pinned to the version you tested.
