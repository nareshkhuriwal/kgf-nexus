# __WORKFLOW_NAME__

Per-object fan-out with a manifest fan-in, generated by `nexusctl init file-fanout`.

```
list_objects --> process_object x N (one per object) --> build_manifest
```

| Task | What it does | Policy |
|---|---|---|
| `list_objects` | Lists objects under `prefix` matching `pattern`, each with a version (mtime or ETag) | at most `MAX_OBJECTS` (500); retried on transient errors |
| `process_object` | **map**: streams one object, returns size, lines, SHA-256 | memoized 30 days on (key, version); `max_bytes=512` |
| `build_manifest` | Checks every object succeeded; writes `manifest_path` atomically | `trigger_rule=all_done`: names every failed object |

`process_object` is the part to replace with your own work (parse, convert,
upload, index...). Keep its return value small: it is what the fan-in carries.

## Bounded fan-in

The platform assembles every child's result into one array for
`build_manifest`. `process_object` declares `max_bytes=512` on its output, so
at submit the control plane proves that `max_fanout x max_bytes` fits its
fan-in limit, and `nexus.entrypoint` refuses to emit a result over 512 bytes.
Anything bigger belongs in object storage, with its path in the result.

## Re-runs process only what changed

Each child is memoized on the listing element, which includes the object's
version. Re-running over the same prefix reads only new or modified objects.

## Storage

Local directories and `file://` work out of the box (mount the data into the
task container). For `s3://bucket/path`, add `boto3` to `requirements.txt` and
give the workers credentials through a secret reference, never a literal.

## Develop

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e /path/to/kgf-nexus/sdk/python -r requirements.txt pytest
pytest
nexusctl workflow compile dag.py --show
```

## Deploy and run

```bash
docker build --build-context nexus-sdk=/path/to/kgf-nexus/sdk/python \
    -t __WORKFLOW_NAME__:0.1.0 .   # then push, and set IMAGE in dag.py
nexusctl workflow submit dag.py --namespace __NAMESPACE__
nexusctl run create __WORKFLOW_NAME__ --namespace __NAMESPACE__ \
    --param prefix=/data/incoming --param 'pattern=*.csv' --wait
```
